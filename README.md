# Trabalho_metodos

## Padrão de saída

| k | d_k | d_k+1 | f(d_k) | f'(d_k) | \|f(d_k+1)\| | \|d_k+1 - d_k\| |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |

Em relação ao **método da secante**, acrescente o campo d_k+2 (o resultado do método naquele passo) ou acrescente o campo d_k-1 (uma das aproximações). Para manter tudo padronizado, importe `<"iomanip">` e utilize a função `setw(15)` em cada campo (garante que o próximo output tenha exatamente 15 casas decimais), além de alinhar os elementos a esquerda usando `left`.
